How to Use API Keys

You can use your API key to authenticate API requests using one of the following methods. Both methods are fully supported, so choose whichever works best for your application:

1. Using Authorization Header
Authorization: Bearer YOUR_API_KEY
2. Using X-API-KEY Header
X-API-KEY: YOUR_API_KEY
Example with curl (using method 1):
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.example.com/resource
Example with curl (using method 2):
curl -H "X-API-KEY: YOUR_API_KEY" https://api.example.com/resource
Security Notice: Keep your API keys secure and never share them publicly. If a key is compromised, revoke it immediately and generate a new one.
